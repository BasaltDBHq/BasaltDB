## Passkey management

M4.1. WebAuthn gives the server no signal when a person deletes a passkey from a device or password manager, so Basalt never learns it on its own. Removal is explicit, on a setup page, and revoked in Postgres. There is no command: `basalt passkey` (`check`, `remove`) is removed, with the `/passkeys/check` and `/passkeys/forget` pages it linked to.

- **Where.** Persona 1: the local setup page's Update check lists the passkeys and removes or adds one ([`PASSKEY_REMOVE` and `PASSKEY_ADD`](setup-page.md#the-update-check)). Persona 2: the connect page after `basalt init --remote` runs again ([Update on the connect page](connect.md#update-on-the-connect-page)). The agent's `basalt init` (or `basalt init --remote`) prints the link; every hint that named `basalt passkey` names it instead.
- **The list.** Every active passkey of the database, at most 100, oldest first: its label, when it was added and when it was last used (`last_used_at`, else never). A passkey of another origin than the page's is listed with its site: it signs only on that site's pages.
- **Removal needs only the admin connection string.** The person owns the database, so the admin login is what allows it, as it allows removing BasaltDB. So a lost device can be removed even when it held the only passkey: the page calls `basalt_meta.revoke_passkey(credential_id, true)`, and asks the person to add a passkey when none is left for its origin.
- **Revoked means refused.** `_verify_assertion` refuses a revoked passkey, so it can no longer approve a held write, sign a revert or sign a large plan. Revocation is admin only and appends `PASSKEY_REVOKED`; an agent role can neither register nor revoke a passkey.
- **The browser.** After a removal of a passkey of the page's own RP ID, the page calls `PublicKeyCredential.signalUnknownCredential({ rpId, credentialId })` when the browser has it, so a password manager may hide or delete it. It is a hint: a browser without it, or a call that fails, is a no-op.
- **Unused passkeys.** The list shows when each was last used, so the person can spot one they no longer have. Nothing is revoked automatically.
